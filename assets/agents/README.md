# Agent identifiers

These graphics identify the applications with Byte Bridge connectors. Supported versions and session modes are documented in [the compatibility matrix](../../packages/byte-bridge/docs/support.en.md). Names and marks belong to their respective owners; their use does not imply endorsement.

Pi uses a typographic π identifier, not an official logo. Claude Code is identified with the Claude family brand mark. `sources.json` records the retrieved source and SHA-256 of each local asset.
