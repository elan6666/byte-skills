# kimi SessionBridge

Explicit managed ACP sessions: `session-bridge host --harness kimi --stdin --json`. Configure an isolated native profile first; credentials are referenced by environment variable, never stored in this plugin. See `docs/acp.zh-CN.md`. Existing TUI attachment is not implied. Installation does not activate native tools.
